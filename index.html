ระบบขออนุมัติค่าใช้จ่ายบริษัทฯ

บันทึกคำขอเบิกค่าใช้จ่าย ติดตามสถานะ และอนุมัติได้ในที่เดียว

สร้างคำขออนุมัติค่าใช้จ่ายใหม่

ที่ วันที่นำเข้า หัวข้อเอกสาร จำนวนเงิน ผู้ขออนุมัติ ผู้อนุมัติ สถานะ วันที่อนุมัติ ลบ
ยังไม่มีคำขออนุมัติค่าใช้จ่าย — เพิ่มรายการแรกด้านบน

รายชื่อพนักงาน (สำหรับเลือกเป็น "ผู้ขออนุมัติ")

    ยังไม่มีรายชื่อพนักงาน — เพิ่มรายชื่อด้านบน
    เข้าสู่ระบบในฐานะ:

    รายการรออนุมัติของคุณ
    ไม่มีรายการรออนุมัติในขณะนี้
    ประวัติการพิจารณาของคุณ
    ยังไม่มีประวัติการพิจารณา
    เข้าถึงการตั้งค่าแล้ว

    ตั้งค่าแจ้งเตือนทาง Gmail

    เมื่อมีคำขออนุมัติใหม่ ระบบจะส่งอีเมลแจ้งเตือนไปยังผู้อนุมัติที่ถูกเลือกโดยอัตโนมัติ ผ่านบริการ EmailJS (ต้องตั้งค่าครั้งแรกตามขั้นตอนด้านล่าง)

    วิธีตั้งค่า EmailJS (ทำครั้งเดียว)

    1. สมัครฟรีที่ emailjs.com แล้วไปที่เมนู Email Services → เพิ่มบริการ → เลือก Gmail → เชื่อมต่อบัญชี Gmail ที่จะใช้ส่ง แล้วคัดลอก Service ID
    2. ไปที่เมนู Email Templates → สร้างเทมเพลตใหม่ ใส่ตัวแปรในเนื้อหาอีเมล เช่น {{approver_name}}, {{requester_name}}, {{title}}, {{amount}}, {{details}}, {{date_imported}} และตั้งช่อง To Email เป็น {{to_email}} แล้วคัดลอก Template ID
    3. ไปที่เมนู Account → General คัดลอก Public Key
    4. นำทั้ง 3 ค่ามาใส่ในช่องด้านบน พร้อมอีเมล Gmail ของผู้อนุมัติทั้งสองท่าน แล้วกดบันทึก

    หมายเหตุด้านความปลอดภัย: Public Key และ Service/Template ID จะถูกฝังอยู่ในหน้าเว็บนี้ ซึ่งเป็นวิธีการทำงานปกติของ EmailJS (ออกแบบมาให้ใช้ฝั่งเบราว์เซอร์ได้อย่างปลอดภัยในระดับหนึ่ง) แต่ไม่ควรใช้ Private Key ใดๆ ในหน้านี้เด็ดขาด และควรตั้งค่า "Allowed Origins" ในบัญชี EmailJS ให้จำกัดเฉพาะโดเมนที่ใช้งานจริง

    นำเข้าข้อมูลคำขอจาก Google Sheet

    ดึงข้อมูลคำขออนุมัติในอดีตจาก Google ชีตมาบันทึกไว้ในระบบนี้ทั้งหมด ระบบจะแสดงตัวอย่างให้ตรวจสอบก่อนยืนยันนำเข้าจริงทุกครั้ง

    เปิดชีต เลือกทุกแถวรวมหัวตาราง (Ctrl+A หรือลากคลุม) กด Ctrl+C แล้ววางในช่องด้านล่าง วิธีนี้ไม่ต้องพึ่งการเชื่อมต่อไปยัง Google จากเบราว์เซอร์เลย จึงไม่มีปัญหาเรื่องสิทธิ์การแชร์หรือการเชื่อมต่อ

    วิธีนำเข้าข้อมูลจาก Google Sheet

    1. เปิด Google Sheet ที่มีข้อมูลคำขออนุมัติในอดีต แล้วตั้งค่าการแชร์เป็น "ทุกคนที่มีลิงก์ - ดูได้ (Viewer)"
    2. แถวแรกของชีตต้องเป็นหัวคอลัมน์ โดยระบบรองรับชื่อคอลัมน์เหล่านี้ (เรียงลำดับใดก็ได้ ไม่ต้องมีครบทุกคอลัมน์ ยกเว้น "หัวข้อเอกสาร"): วันที่นำเข้าเอกสาร, หัวข้อเอกสาร, รายละเอียด, จำนวนเงิน, ผู้ขออนุมัติ, ผู้อนุมัติ, สถานะ (หรือ สถานะการอนุมัติ), วันที่อนุมัติ (หรือ วันที่แก้ไขล่าสุด)
    3. คอลัมน์สถานะรองรับคำว่า อนุมัติ / ไม่อนุมัติ / รออนุมัติ หรือ รอการอนุมัติ (ถ้าเว้นว่างจะถือว่ารออนุมัติ)
    4. วิธีที่ 1 (ดึงจากลิงก์): คัดลอกลิงก์ของชีตมาวางในช่องด้านบน แล้วกด "ดึงข้อมูลจากลิงก์" — วิธีนี้บางเบราว์เซอร์อาจบล็อกการเชื่อมต่อข้ามโดเมนไปยัง Google ทำให้ดึงไม่สำเร็จแม้ตั้งค่าแชร์ถูกต้องแล้ว
    5. วิธีที่ 2 (คัดลอก-วาง, แนะนำ): เปิดชีต เลือกทุกแถวที่ต้องการ (รวมหัวตาราง) คัดลอก แล้ววางลงในช่อง "วางข้อมูลที่คัดลอก" ด้านบน จากนั้นกด "อ่านข้อมูลที่วาง" — ไม่ต้องพึ่งการเชื่อมต่อใดๆ จึงได้ผลแน่นอนกว่า

    หมายเหตุ: ชื่อ "ผู้อนุมัติ" ในชีตควรตรงกับชื่อในระบบเป๊ะๆ (คุณประพัฒน์ ศิริพัฒนพูนผล / คุณสุวรรณี จิตตินรเศรษฐ์) มิฉะนั้นรายการที่ยังรออนุมัติจะไม่ปรากฏในเมนู "อนุมัติคำขอ" ของผู้อนุมัติท่านนั้น (แต่จะยังแสดงในตารางหลักตามปกติ)

    เปลี่ยนรหัสผ่านผู้อนุมัติ

    ตั้งรหัสผ่านใหม่ให้ผู้อนุมัติแต่ละท่าน ใช้ในกรณีลืมรหัสผ่านหรือต้องการเปลี่ยนใหม่ โดยไม่ต้องให้ผู้อนุมัติล็อกอินเข้าไปเปลี่ยนเอง
